Hỏi bằng tiếng Việt tự nhiên. Kết quả kết hợp tìm theo từ khóa (BM25) và theo ngữ nghĩa (embedding đa ngôn ngữ), luôn kèm văn bản gốc để đối chiếu.

Cách hoạt động
1. Thu thậpCrawl cổng thông tin sinh viên hằng tuần bằng Airflow, có kiểm tra chất lượng dữ liệu.
2. Chia đoạnTách theo Chương / Điều / Khoản, gắn ngày ban hành và cờ phiên bản mới nhất.
3. BM25Tìm theo từ khóa, chạy bằng JavaScript (khớp 100% với bản Python).
4. EmbeddingMiniLM đa ngôn ngữ (ONNX) mã hóa câu hỏi ngay trong trình duyệt.
5. Hợp nhấtReciprocal Rank Fusion ghép hai danh sách kết quả.

Bản đầy đủ (chạy local) còn có reranker, bộ lọc nâng cao và hỏi đáp kèm trích dẫn bằng LLM — xem README trên GitHub.
