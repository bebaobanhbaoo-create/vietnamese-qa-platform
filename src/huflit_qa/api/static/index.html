Hỏi đáp quy chế HUFLIT

Trả lời từ quy chế và thông báo trên cổng thông tin sinh viên, kèm trích dẫn nguồn. Kiểm tra lại văn bản gốc trước khi làm thủ tục.

Bản demo này chỉ tìm kiếm trong 1.209 đoạn quy chế và thông báo (BM25 + embedding, hợp nhất bằng RRF). Phần hỏi đáp có trích dẫn chạy với LLM local qua Ollama — xem ảnh động trong README của repo.
